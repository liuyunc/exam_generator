# Roadmap

Exam Generator is evolving from a JSON chunk question generator into a knowledge assessment engine for training, certification, and knowledge-base evaluation.

## v0.2

- Question quality scoring and duplicate detection
- Better difficulty calibration across easy, medium, and hard questions
- Expanded export templates for teacher review
- Additional tests for API validation and export edge cases

## v0.3

- RAG retrieval mode for larger knowledge bases
- Multi-language question generation
- Better source citation controls
- Support for PPTX and additional document ingestion pipelines

## v0.4

- Reviewer workflow for teachers and domain experts
- Batch generation jobs with resumable progress
- LMS-friendly import/export formats
- Docker Compose deployment example

## v1.0

- Stable public API contract
- Enterprise deployment guide
- Pluggable model provider configuration
- Production-ready documentation and release checklist
